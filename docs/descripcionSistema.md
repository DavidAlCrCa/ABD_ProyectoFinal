# Sistema de Gestión de Gimnasio

## 1. Descripción del proyecto

El proyecto consiste en desarrollar una base de datos para administrar la información de un gimnasio. Su propósito es facilitar el registro y control de los socios, entrenadores, membresías, clases, horarios y pagos.

El sistema permitirá organizar la información en un solo lugar, evitando registros duplicados y facilitando la consulta de los datos.

La base de datos será desarrollada en SQL Server 2025 Developer, utilizando un modelo relacional que permita mantener la integridad de la información.

## 2. Problema que se busca resolver

Los gimnasios necesitan llevar un control de sus socios, los servicios que ofrecen y los pagos que reciben. Cuando esta información se administra manualmente, pueden presentarse problemas como registros duplicados, pérdida de información o dificultades para consultar los pagos y las membresías.

Por esta razón, se propone desarrollar una base de datos que permita almacenar y relacionar la información de manera organizada.

## 3. Objetivo general

Diseñar e implementar una base de datos relacional que permita administrar la información de un gimnasio de manera organizada, segura y eficiente.

## 4. Objetivos específicos

- Registrar y administrar la información de los socios.
- Gestionar los entrenadores y las clases disponibles.
- Llevar un control de las membresías.
- Administrar los horarios y las inscripciones a clases.
- Registrar los pagos realizados por los socios.
- Facilitar la consulta de información para generar reportes.

## 5. Actores principales

**Administrador:** Encargado de gestionar la información del gimnasio y consultar los registros.

**Socio:** Persona inscrita en el gimnasio que puede adquirir una membresía y participar en clases.

**Entrenador:** Persona responsable de impartir las clases programadas.

## 6. Procesos principales

1. Registro de nuevos socios.
2. Asignación y control de membresías.
3. Registro de entrenadores.
4. Programación de clases y horarios.
5. Inscripción de socios en las clases.
6. Registro y consulta de pagos.

## 7. Alcance del sistema

El sistema se enfocará en la administración de la información del gimnasio mediante una base de datos relacional. Incluirá la creación de tablas, relaciones, restricciones de integridad y consultas SQL.

Además, se implementarán mecanismos de seguridad, optimización, respaldo y recuperación de datos, así como la visualización de información mediante Power BI.

El proyecto no contempla el desarrollo de una aplicación web o móvil.
